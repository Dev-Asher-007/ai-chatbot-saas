# AI Chatbot SaaS

A startup-ready MVP for an AI customer support chatbot SaaS that helps businesses automate support with a simple dashboard and a smart chat experience.

## Features

- Landing page and startup-style marketing site
- Dashboard for managing AI chatbots
- Messaging API route with OpenAI integration ready
- Stripe-ready billing structure and pricing page
- Responsive UI built with Next.js and Tailwind CSS

## Stack

- Next.js 14
- TypeScript
- Tailwind CSS
- OpenAI API
- Vercel-ready

## Getting started

1. Install dependencies:
   npm install
2. Copy environment variables:
   cp .env.example .env.local
3. Start the app:
   npm run dev
4. Open http://localhost:3000

## Environment variables

```bash
OPENAI_API_KEY=your_key_here
NEXT_PUBLIC_APP_URL=http://localhost:3000
```
